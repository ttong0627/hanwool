# 한울 배송 — 기사 배정 규칙 & 배송 순번 규칙

> 작성일: 2026-06-07 · 기준: 실제 운영 코드(`dispatch_service.py`, `route_service.py`, `orders.py`)
> 관련 문서: `docs/ADDRESS_STRATEGY.md`

이 문서는 한울 경안시장 집배송 서비스의 **두 가지 핵심 규칙**을 정의한다.

1. **기사 배정 규칙** — 누가 어떤 주문을 맡는가
2. **배송 순번 규칙** — 한 기사가 어떤 순서로 도는가

---

## 1. 기사 배정 규칙

### 대전제

- **무조건 최고관리자 배정이 업무 시작점이다.** 기사 자가배정·"40건 초과 요청" 흐름은 폐지됨.
- 배정된 주문은 **`배송준비(assigned)`** 상태가 된다.
- 기사가 앱에서 **「출근 수락(배송 출발)」** 을 누르면 배정분 전체가 **`배송중(in_transit)`** 으로 출발한다. (2단계: 배정 → 준비 → 출발)
- 배정 즉시 해당 기사의 **배송 순번이 자동 계산**된다(§2).

### 배정 경로 (3가지)

| # | 경로 | 동작 |
|---|------|------|
| ① | **동(洞) 단위 배정** (모바일 기본) `POST /orders/dispatch/by-dong` | 관리자가 **동을 선택해 특정 기사에게** 배정. 선택한 동의 **준비단계(pending·assigned)** 주문만 그 기사로 이동(이미 시작된 `배송중`·`완료`는 건드리지 않음). 2명 이상은 동을 나눠 배정. 배정 후 해당 기사 순번 자동 재계산 |
| ② | **균등 분배 배차** `POST /orders/dispatch` → `run_dispatch()` | **동별로 묶은 뒤**, 주문 수가 많은 동부터 **가장 적은 부하의 기사**에게 배정(greedy bin-packing). **같은 동 = 같은 기사**(동선 보존). 1~18명 지원 |
| ③ | **개별 주문 배정** `PUT /orders/{id}/assign` | 한 건을 특정 기사에게 배정 → 그 기사 순번 재계산 |

### 분배 원칙 (경로 ②)

- **동 우선순위 규칙 없음** — `delivery_zones.priority` 컬럼은 존재하나 배차/순번에 사용하지 않는다.
- **주문 수 기준 균등 분배** — 기사별 물량 편차 최소화.
- **누락 0** — 주문이 있는 모든 동(18개 허용동)은 어떤 기사 수에서도 반드시 배정된다.
- **균형 점검** — 평균 대비 `IMBALANCE_RATIO`를 초과한 기사는 "이관 허용"으로 표시(`_flag_imbalance`).

### 배송 허용동 (18개)

- 핵심 4개: **경안동, 송정동, 쌍령동, 탄벌동**
- 추가 14개: 고산동, 매산동, 목동, 목현동, 문형동, 삼동, 양벌동, 역동, 장지동, 중대동, 직동, 추자동, 태전동, 회덕동
- 배송 가능 동은 `delivery_zones`(`is_active = true`)에서 관리. 법정동과 실제 구역이 다르면 `address_overrides.force_service_dong`로 현장 기준 우선.

## 2. 배송 순번 규칙

### 핵심

- **기사별로 독립 계산** — 각 기사 주문에 1번부터 순번 부여.
- **출발지 = 경안시장**(`MARKET_LOCATION`).
- **순수 거리 기반** — 동 구분/우선순위 **없음**.

### 계산 방식 (`route_service.optimize_route_with_kakao_matrix`)

1. **Kakao Mobility 실제 도로거리 행렬**로 최적화 — 최근접 이웃(nearest-neighbor) + 2-opt 개선.
2. Matrix API 사용이 불가능하면 **직선거리(좌표) 기반** 최적화로 폴백(`optimize_route`).
3. 경안시장에서 출발하는 **최단 경로**(성남 방향으로 빠지는 종료 편향, `_optimize_shortest_to_seongnam`).

### 적용 시점

- 배정/재배정 시 `_auto_sequence_for_driver(driver_id)`가 자동 호출 → `sequence_source = "auto"`.
- 계산 후 각 기사에게 WebSocket `route_updated` 푸시로 즉시 반영.

### 좌표 출처 (순번 정확도의 전제)

- 주소 좌표는 **DB(`address_cache`) 우선**, 저장된 좌표가 없을 때만 Kakao API 호출 후 저장(재사용).
- 좌표가 없는 주문은 순번 계산 전 자동 재지오코딩.

### 수동 조정

- 기사는 앱에서 **「순번조정」** 버튼 → 순번 왼쪽 이동 아이콘 → 순서 이동(MoveStopModal) 가능.
- 수동 조정분은 `PUT /orders/resequence`로 저장되며 `sequence_source = "manual"`.

## 한 줄 요약

> **배정** = 최고관리자가 (동 단위 또는 균등 분배로) 기사에게 배정, 같은 동은 같은 기사, 동 우선순위 없음 ·
> **순번** = 경안시장 출발, 기사별 거리(실제 도로) 최단 경로 자동 계산, 동 구분 없음, 기사가 수동 조정 가능.
